# 资产提示词组装

## 组装顺序

先按[双层风格菜单](style-presets.md)锁定风格 ID。`画面风格`依次合并视觉媒介正向母版、题材气质正向母版和有效自定义补充；把这一整段逐字放入每条`完整生成提示词`。风格切换时同步更新 ID、名称、正向母版和对应排除项。

用户明确说“默认”或“不挑风格”时采用 `STYLE-M01-G01｜真人影视×都市现实`；已指定的风格按用户选择执行。同一批次人物、群像、场景共用一种风格；用户要求混合风格时按风格分独立批次。

### 场景提示词组装

每条场景提示词按 `空间锚点 → 时间／空间状态增量 → 画面风格 → 四视图版式` 组装。`画面风格` 内保持上述媒介、题材、自定义顺序。

固定四视图版式段：

```text
16:9横版画面，8K，7680×4320，同一场景四视图，四宫格构图：第一格全景，第二格中景平视，第三格近景斜45度，第四格全景俯拍；四格严格保持空间结构、坐标、门窗、家具、材质、关键道具、时间与空间状态一致；严格遵循已锁定的项目视觉媒介与题材气质，细节丰富，高质量，无人。
```

场景通用负面提示词：

```text
人物、人影、人体局部、人物倒影、空间比例错误、建筑尺度错误、透视错误、左右镜像错误、房间结构漂移、门窗错位、家具数量变化、家具悬浮、关键道具位置漂移、材质漂移、四视图不一致、非四宫格、视图顺序错误、第四格非俯拍、文字、水印、logo、二维码、品牌标识、过曝、死黑、无逻辑脏乱。
```

### 人物提示词组装

每条人物提示词按 `身份锚点 → 可视化气质锚点 → 服装状态 → 画面风格 → 固定人物版式 → 剧情道具规则` 组装。`画面风格` 内保持上述媒介、题材、自定义顺序。

固定人物版式段：

```text
16:9横版人物资产图，纯白背景；左上为人物面部正面特写和人物面部侧面特写，两张面部特写保持同一面部结构、发型、妆容和服装状态；右侧为人物正面、侧面、背面全身三视图，三视图面部、发型、身材和服装严格一致；人物自然站立，人物双手空置，手臂自然下垂或置于身体两侧；严格遵循已锁定的项目视觉媒介与题材气质。剧情需要道具时，道具独立放在画面左下方、两张人物面部特写正下方，与人物身体完全分离，无手部接触；没有道具时左下区域纯白留空。
```

单人人物通用负面提示词（其中“群像”仅用于防止单人资产混入多个人，不得用于群像资产）：

```text
身份漂移、年龄漂移、脸型变化、五官变化、发际线漂移、体型漂移、缺少人物面部正面特写、缺少人物面部侧面特写、两张面部特写不同脸、面部特写发型或妆容不一致、三视图不同脸、三视图服装不一致、姿态僵硬、肢体畸形、多手多指、服装结构错误、人物手持道具、手握物品、手拿物品、手托物品、手捧物品、手提物品、道具挂在人物身上、道具与手部接触、道具遮挡人物、道具出现在右侧三视图区、无道具时左下出现物品、裁切缺失、杂乱背景、群像、文字、水印、logo、二维码、品牌标识。
```

负面提示词用于补充正向画面要求：合并`人物、群像或场景通用排除项＋所选视觉媒介排除项＋所选题材气质排除项＋自定义排除项`，去重并检查与已选风格相容。例如 2D 国漫批次保留二维动画表达，对无关的三维渲染或真人摄影使用排除项。群像通用排除项见[群像资产](groups.md)，单人词条“群像”只用于单人人物行。
