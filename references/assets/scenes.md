# 场景资产

按[资产工作流](workflow.md)确定范围；本文件负责物理空间母版、时间／空间状态和四视图。列结构见[工作簿结构](workbook-contract.md)。

## 物理空间母版

一个可复用的物理空间分配一个稳定场景 ID，如 `SCN-001`。同一房间的全景、近景、门口方向、桌面特写和不同机位沿用该 ID。原文确认是不同房间、楼层、建筑，或永久结构已变化到需要另一套空间锚点时，建立新的场景 ID。

以**主入口朝室内**的观察方向固定前后左右，并写成逐字复用的空间锚点：

- 空间类型、长宽高比例与层高；
- 主入口、次入口、门、窗和走廊方位；
- 墙体、柱体、楼梯和分区关系；
- 固定家具的数量、朝向和相对坐标；
- 关键道具的固定归属与默认位置；
- 地面、墙面、顶面和主要家具材质；
- 主色、辅助色和长期使用痕迹。

从各机位描述同一坐标系，使门窗、家具、材质和左右关系在各状态中对应。生成平台支持参考图、场景引用、seed 或模型参数时，各状态复用同一场景母版参考与参数。

## 时间与空间状态

以**时间段 × 空间状态**确定场景状态。白天、黄昏、晚上、深夜等明显时间变化建立不同状态；正常完整、停电、凌乱、遭到破坏、火灾后、修复后、临时封锁等明显空间变化也建立不同状态。同一时间下的不同破坏程度、同一空间状态下的白天与夜晚分别编号。

天气、照明和临时陈设显著改变整体画面时写入状态名称与状态增量；机位、景别、人物站位或短暂移动道具沿用当前状态。状态 ID 从 `SCN-001-T01` 连续递增；名称同时概括时间与空间状态，如“白天完整状态”“夜晚被破坏状态”。调用标签固定为 `状态ID｜场景名称｜状态名称`。同一场景、时间和空间状态再次出现时复用 ID 与标签。

## 四宫格四视图

场景资产为 16:9 横版，提示词指定目标 8K、7680×4320。同一状态在四格中复用空间坐标、门窗、固定家具、材质、关键道具与时间／破坏状态：

1. 第一格全景：展示主要空间结构和功能分区。
2. 第二格中景平视：成人正常视线高度，展示核心使用区域。
3. 第三格近景斜45度：展示关键材质、家具、物品和使用痕迹。
4. 第四格全景俯拍：展示空间布局、动线与家具坐标关系。

四格呈现空场景，使空间结构本身清晰；清晰人物、模糊人影、人体局部和人物倒影统一归入场景负面提示词。固定提示词段见[提示词组装](prompt-assembly.md)。
