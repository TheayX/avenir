# 资产交付校验

按本次实际交付的类别检查。先运行确定性脚本，再核对原文事实、可见构成与提示词语义；修正影响行后重新运行对应检查。

## 共用检查

- **范围与证据：** 处理范围的章节／小节及已有分镜视频编号逐一列齐。每个实体状态都能追溯到来源章节／段落位置、使用区间、状态切换依据与原文证据；制作补足和弱推断有独立标记。
- **ID 与状态：** 同一实体复用唯一主 ID；状态按各类别的触发条件建立，同一状态跨章合并来源。相同主 ID 的行连续相邻并按状态 ID 升序；调用标签精确采用 `状态ID｜名称｜状态名称`。
- **风格与提示词：** 风格在生成前由用户确认或明确选择默认。相同批次的人物、群像、场景复用风格 ID、视觉媒介、题材气质与有效自定义补充；混合风格各成独立批次。`画面风格`包含对应正向母版并逐字进入完整提示词；负面项与当前风格相容。
- **文件：** 每份 Excel 只有相应的“人物资产”“群像资产”或“场景资产”工作表。每行图片比例为 `16:9`；首行加粗、冻结首行、开启筛选、自动换行，长文本列可读。

## 人物

- 覆盖清单列齐每节出场栏、画面、动作／情绪、台词、OS、画外音及小说中实际现身或行动的人；每个条目映射到人物或群像 ID。单句台词、单镜出场和可辨认匿名人物均有对应资产；匿名功能名限定场景或组织。
- 人物画像分别填写对白、决策、人际与情绪模式，标注原文位置及 `明确`、`强推断`、`弱推断`。证据少的角色使用“证据不足”和最小制作补足；完整提示词采用有依据的稳定特征。
- 同一人物各状态逐字复用人物画像、身份锚点和可视化气质锚点；气质锚点写可见、克制的神态和姿态。新状态对应服装切换，相同服装复用状态 ID。
- 人物图左上有正面与侧面面部特写，右侧有正面、侧面、背面全身三视图；脸、身材、发型和服装一致。人物自然站立、双手空置；剧情道具仅在左下独立展示，无道具时左下纯白留空。

## 群像

- 群像候选逐一记录入选或筛选原因。入选组合有原文支持的集体身份、人数依据、成员和相对位置；人数未知时“人数未明”与可视人数方案分别填写。
- 具名成员引用人物 ID／服装状态，并逐字复用身份锚点与服装状态。群像锚点在同一主 ID 下逐字一致；新状态对应成员构成或集体服装显著变化。
- 群像图呈现相对位置清楚的全身集体、纯白背景、双手空置；需要的道具在左下独立展示。负面词针对缺员、增员、同脸、融合、身份或服装漂移，保留“群像”作为正向主体。

## 场景

- 相同物理空间复用场景 ID 和逐字相同的坐标基准、空间锚点、固定结构、家具与材质。新状态对应时间段或空间状态变化；白天／夜晚和完整／被破坏等组合分别映射。
- 完整提示词包含目标 `8K`、`7680×4320`、四宫格构图与已锁定画面风格。四格依次为第一格全景、第二格中景平视、第三格近景斜45度、第四格全景俯拍；门窗、家具、材质、道具位置和状态在四格一致。四格呈现无人空间。

## 脚本与语义复核

交付人物 Excel 时，把逐节覆盖清单保存为内部 JSON，运行：

```text
scripts/validate_cast_coverage.py <覆盖清单.json> --characters <人物.xlsx> [--groups <群像.xlsx>]
```

每份实际生成的 Excel 运行 `scripts/validate_asset_consistency.py <资产.xlsx>`；同时交付群像和人物时，对群像再运行 `scripts/validate_asset_consistency.py <群像.xlsx> --characters <人物.xlsx>`。只交付群像或场景时运行适用的单文件检查，并人工核对来源和状态；群像有既有人物 Excel 时也用 `--characters` 检查引用。

脚本通过后抽查每个主 ID 的首行和状态切换行，核对原文证据、人数、锚点和画面细节。发现遗漏或冲突时补齐并重新校验，完成后交付。
