# 分镜输出契约

本文件是正式分镜的唯一格式依据。输出纯文字分镜；只有用户明确修改时才调整格式。

## 视频编号与容量

- 每个视频编号的时长与镜头数按[时长与有声节奏](pacing.md)确定。镜头从 0 秒连续覆盖至标题所写的总时长，没有重叠或空档。
- 首个编号默认为 01；已有编号时从下一个连续编号开始。每节有简短准确的剧情标题，只承载一个清晰的主要事件；重要转折、证据揭示或场景明显变化时，按剧情容量另起编号。
- 每节最多两个独立场景，可以只有一个；【本节固定场景】只填简短地点名，如“饭店大厅，饭店前台”。不得写“客厅与相连玄关”等连接式名称，也不填时间或光效。第三个地点另起编号。
- 【本节出场人物】最多四个角色单位，包括姓名人物、无名但需独立表演者、电话或消息发声者、画外发声者和固定群像。每节最多一个群像；群像只在原文确有共同表演需要时使用，注明固定人数。超过四个角色单位时按原文顺序拆节，不能删人物。
- 单镜实际可见人数最多四人；群像按真实可见人数计算。每镜优先一至两名清晰人物，双人对话原则上只出现双方。多人节的【画面】逐镜明确列出实际可见者。
- 每节【本节有声字数】不得超过 85 字。只统计各镜【台词】【OS】【画外音】中实际播读的引号内正文：汉字、数字、拉丁字母逐字计数；人物名、来源名、情绪标签、标点和空格不计。准确填写声明值。超过上限的原文台词顺延到下一编号，不删改。

## 固定顺序与写法

标题固定写作：

`## 视频编号XX（剧情标题，T秒 / 共N镜）`

T 填本节总时长，通常为 13、14 或 15。N 填实际镜头数。

其后按顺序填写以下四项，栏目之间空一行：

1. `【本节固定场景】地点甲，地点乙`
2. `【本节出场人物】人物甲，人物乙`
3. `【本节有声字数】XX字`
4. `←故事开篇：...`（视频编号 01）或 `←承上视频编号XX：...`（其他编号）

承上要写清上一编号末镜的人物位置、姿态、面朝方向、手部动作、关键道具位置、时间与光效，以及即将发生的动作。首镜的【摄影机位置】【画面】【位置承接】再用人物姓名和具体方向写出当前画面，供单独制作和跨编号剪辑核对；比较结论只用于内部规划。故事开篇写第一个画面的初始场景、人物位置、姿态和动作。

镜头标题固定为 `镜头1 / SC1（0—X秒）`、`镜头2 / SC1（X—X秒）`……`镜头N / SC1（X—T秒）`，编号从 1 连续至 N，SC1 写法不变。每个镜头完整填写下列十个栏目，名称与顺序不变，栏目之间空一行：

| 顺序 | 栏目 | 内容 |
| --- | --- | --- |
| 1 | 【时间标识】 | 大概时间段｜该场景统一光效 |
| 2 | 【摄影机位置】 | 本镜相对人物或场景实体的具体机位、景别、主拍对象、必要的前后景关系 |
| 3 | 【运镜】 | 固定镜头；或写明剧情触发点、运动方式、目标和停点的简单运镜 |
| 4 | 【画面】 | 直接可见的人、物和空间位置 |
| 5 | 【动作/情绪】 | 可表演的动作、表情、视线与情绪变化 |
| 6 | 【位置承接】 | 人物位置、姿态、朝向、手部和道具，动作起终点 |
| 7 | 【OS】 | 无，或人物【内心独白｜情绪】：“原文内容” |
| 8 | 【画外音】 | 无，或唯一来源【情绪】：“原文内容” |
| 9 | 【音效】 | 必要的环境声、动作声或音乐变化；没有则“无” |
| 10 | 【台词】 | 无，或人物【情绪】：“原文台词” |

一镜最多一个声音来源。若【台词】【OS】【画外音】之一有内容，其他两项都写“无”；完全无声则三项均写“无”。电话声音、消息播读、证据信息播读也各算一个独立来源；一问一答至少两镜，说话人切换必须切镜。不要添加【本镜出场人物】【视线关系】【光效】【本节出场道具】或其他新栏目；相关信息写进现有栏目。

十栏写当前镜头实际可见、可演或可听的成稿内容。每镜可独立阅读：从本镜文字能确定当前场景、人物画面位置与朝向、机位、光效、关键道具所在处及本镜动作。镜头选择理由、与相邻编号的比较和制作检查语在内部完成；【摄影机位置】直接给出本镜的可拍机位。

每节最后一行用 `→衔接视频编号XX：` 写明下一编号必须承接的位置、动作、道具、剧情事件；即使当前小说章节结束，只要故事尚未结束，仍写下一编号承接。整部小说结束时用 `→本章结束：` 写具体最终画面状态。下一节的承上必须与前节结尾对应，人物、道具和光效不得重置。

## 结构模板

每一镜均按此字段顺序完整展开；占位说明不留在成稿中。

```text
## 视频编号01（剧情标题，T秒 / 共N镜）

【本节固定场景】场景名称

【本节出场人物】人物名称

【本节有声字数】XX字

←故事开篇：人物初始位置、姿态、动作、关键道具和时间光效状态。

镜头1 / SC1（0—X秒）

【时间标识】下午｜统一光效描述

【摄影机位置】……

【运镜】……

【画面】……

【动作/情绪】……

【位置承接】……

【OS】无

【画外音】无

【音效】……

【台词】人物【情绪】：“原文台词。”

……按实际镜头数继续，每镜完整填写十个栏目，末镜结束于T秒。

→衔接视频编号02：下一编号须承接的具体位置、动作、道具和剧情事件。
```
