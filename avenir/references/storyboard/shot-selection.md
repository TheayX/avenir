# 镜头选择

本文件用于决定每段原文由谁入画、取什么景别、何时切镜。先确定观众此刻必须看清的人、动作或信息，再选能清楚呈现它的构图。对白驱动的场景以稳定轴线、自然的中景与中近景为基础；景别和机位随剧情重点变化，不按固定顺序轮换。

## 先判断画面任务

逐段确认三件事：当前信息由谁说出或做出；谁的反应影响观众对它的理解；是否有原文中的物件、动作或空间关系必须同时看见。声音来源与画面主体可以不同：人物继续说原文台词时，画面可留给有剧情依据的听者反应或双人关系。镜头只承担一个主要视觉任务，并让该任务在分配时长内可见、可演。

| 当前剧情重点 | 优先考虑的画面 | 选择依据 |
| --- | --- | --- |
| 建立新场景、站位或人物关系 | 能看清参与者位置的双人或关系中景 | 让观众先知道谁对谁说话、重要物件在何处；交代完成后转入当前信息重点。 |
| 说话者提出新事实、要求或态度 | 说话者中景或中近景 | 表情、手势和发声对象共同构成信息；按原文的语义或态度变化决定是否切近。 |
| 听者的理解、迟疑或态度变化影响剧情 | 听者反应镜、越肩镜或双人镜 | 画面让观众看到话语落在谁身上；说话者可在画外继续原文台词。 |
| 双方的距离、对抗、支持或权力关系发生变化 | 双人镜、越肩镜或带前后景的关系镜 | 同时保留双方的位置与视线，让关系变化在同一空间里成立。 |
| 原文中的证据、合同、消息或道具产生新信息 | 人物与物件同框的中近景，必要时切细节 | 先让观众知道物件属于谁、在何处，再看必须读清或看清的部分，随后接住人物反应。 |
| 起身、交接、行走、转身或其他关键动作 | 能容纳动作起点、路径和终点的中景或较宽画面 | 动作过程、左右手和道具去向清楚后，再按新信息或反应收紧。 |
| 原文中的情绪转折需要看清面部细节 | 近景或特写 | 把较紧的景别留给确有变化的表情、目光或关键细节，避免整段对话始终同样紧。 |

景别是信息取舍：中景保留身体与空间，中近景兼顾表情和关系，近景突出反应或细节。景别的效果取决于当前剧情和前后镜头，不由“激烈台词”单独决定。双人对话可在双人镜、越肩镜和单人镜之间选择；保持已建立的轴线侧、人物左右、视线和背景参照。

## 决定切镜时机

原文出现新的说话人、新信息落点、听者反应、关键动作阶段或关系变化时，判断观众是否需要换一个可见重点。需要时切到承载该重点的镜头；当前构图已经完整呈现时，可让表演在同一镜内继续。长台词先辨认提出事实、发问、回应、强调态度及指向具体人物、动作或物件等语义落点；需要切镜时按这些落点分配台词与画面。拼接后保留原文字词、标点与顺序，切镜本身不承担新增剧情。

相邻镜头保持自然的空间和景别关系，并让后一镜出现可辨的画面变化。长句拆成接续镜头时，按各段台词的重点在说话者、听者、双人关系、关键物件及动作之间选取合适主体；同一主体仍有不同语义落点时，用有意义的景别、角度或构图变化呈现强调。先为每镜写出具体画面，再并排比较机位、主体、前景和动作；若相邻镜头实际画面重复，依据各段台词的重点重新选择可辨的画面。相邻视频编号的末镜与首镜按[镜头设计](shot-design.md)成对规划。

## 输出前复核

- 对每镜用一句内部判断说明“这段原文需要观众看清谁或什么”；正式分镜仍使用现有十栏。
- 核对画面中的人物、物件、目光落点与动作阶段是否具体可见；听者反应符合原文人物的当下态度，关键物件的展示顺序与原文一致。
- 通读同一场对话：镜头切换自然，主体与构图随台词重点推进；逐对核对同一视频内部相邻镜头，分别能说出两镜具体拍到的内容。连续三镜都是同一人物相似近景时，第三镜呈现明确的新视觉信息或实质变化。较紧景别和细节镜承担明确的信息或情绪任务，人物位置、轴线、光效和道具保持连续。
