## 1. 选择与锁定流程

人物、群像、场景或全部资产模式在生成 Excel 前执行：

1. 根据原文时代、题材、世界观、冲突和目标受众给出不超过三组推荐组合及简短理由。资产单独模式在收到可读素材的同一轮完成范围汇报与风格菜单展示。
2. 用两道可点击单选题分别展示视觉媒介和题材气质，保留各自的自由文本入口；按用户确认的两层选择继续。用户已明确两层选择时直接进入下一步。
3. 用户确认后生成项目风格ID：内置组合使用 `STYLE-Mxx-Gxx`；完全自定义使用 `STYLE-CUSTOM-01`。
4. 把风格ID、视觉媒介、题材气质、自定义补充、正向母版、负面母版和确认依据写入风格档案。
5. 同一处理范围的人物、群像、场景和所有状态复用同一风格档案。用户改变选择时同步更新整个范围的资产提示词。

默认组合只在用户明确回复“默认”或“不挑风格”时启用：`STYLE-M01-G01｜真人影视×都市现实`。

## 4. 自定义风格

- 用户可以在任一内置组合后追加导演、摄影、材质、色彩、年代、地域或参考作品级描述，写入“自定义风格补充”。
- 用户完全自定义视觉媒介和题材气质时使用 `STYLE-CUSTOM-01`；“视觉媒介”和“题材气质”填写用户确认的名称，与内置选项清楚区分。
- 把自定义参考作品或艺术家转写成可见的摄影、线条、材质、色彩与构图规则，并按实际需要建立对应排除项。
- 自定义要求与 16:9、人物版式、双手空置、道具左下、场景无人、四宫格或锚点一致性有冲突时，列出具体冲突，请用户决定以哪项为准，再生成受影响的资产。

## 5. 提示词组装与一致性

- `画面风格`完整写入所选媒介母版、题材母版和有效自定义补充；`完整生成提示词`逐字包含整段“画面风格”。
- `负面提示词`合并资产通用项、媒介项、题材项和自定义排除项，去重并核对与当前正向风格相容。
- 人物、群像和场景共用风格 ID 与两层选择，各自使用身份／群像／空间锚点、状态增量和版式。
- 内置风格 ID 与选择一一对应，例如 `STYLE-M02-G03` 对应 `3D国漫×仙侠玄幻`。
- 同一 Excel 内的资产行使用同一风格组合；同批次各份 Excel 也保持一致。用户明确要求混合风格时拆成独立批次，每批和每份 Excel 锁定一种风格。

## 6. 推荐逻辑与交互格式

根据原文可参考以下推荐，实际选择以用户确认和项目证据为准：

| 原文特征 | 优先推荐 |
|---|---|
| 当代职场、家庭、情感现实题材 | 真人影视×都市现实；2D国漫×都市现实 |
| 历史权谋、宫廷、传统战争 | 真人影视×古装历史；3D国漫×古装历史；水墨插画×古装历史 |
| 修仙、神话、东方玄幻 | 3D国漫×仙侠玄幻；2D国漫×仙侠玄幻；水墨插画×仙侠玄幻 |
| 明确年代生活、家族史 | 真人影视×年代复古；水墨插画×年代复古 |
| 刑侦、调查、密室、社会悬疑 | 真人影视×悬疑犯罪；美式漫画×悬疑犯罪 |
| 近未来、太空、人工智能、废土 | 真人影视×科幻未来；3D国漫×科幻未来；美式漫画×科幻未来 |

### 可点击选择题

环境支持交互式选择题时优先使用；可以使用 `request_user_input_async` 或当前可用的同类控件，一次展示视觉媒介和题材气质两道单选题，并保留自由文本入口：

- 第一题：视觉媒介，包含6个内置选项；自由文本占位提示写“填写其他视觉媒介”。
- 第二题：题材气质，包含6个内置选项；自由文本占位提示写“填写其他题材气质”。
- 根据题材分析把每题最适合的内置选项移到第一位，并在标签末尾写“（推荐）”；推荐项仍需用户点击确认。
- 每层选择一个选项；用户要求混合风格时按确认的组合建立独立资产批次。
- 控件返回结果后完成 ID 映射并继续制作。

如果控件每题最多三项，先让用户选择媒介／题材大类，再展示所选大类中的具体选项；两层各确认一项后锁定风格。推荐项顺序依据当前原文动态调整。
