# 群像资产

按[资产工作流](workflow.md)读取全范围。群像描述被叙事作为一个集体呈现的人；具名成员与[人物资产](characters.md)共用身份和服装状态。

## 候选、成员与状态

逐节记录群体称谓、首次及后续出现位置、可见人数或人数范围、共同身份、共同行动与剧情作用、衣着、相貌、成员证据和入选判断。原文把多人作为集体呈现，或具名角色组合有明确同框资产用途时建立群像。偶然同框、纯背景人潮、只有泛称而缺乏集体视觉依据的候选，记录筛选原因并保持为候选。

同一集体跨章节和地点复用 `GRP-001` 等主 ID；群像名称采用原文支持的称谓，例如“城门守军”“茶馆伙计”“主角小队”。分别记录不同组织及不同时期的成员构成。群像锚点固定群体身份、已知成员和辨识关系、原文支持的人数范围与稳定集体视觉特征。

具名成员引用对应 `CHR-xxx` 与服装状态 `CHR-xxx-Sxx`，完整群像提示词逐字复用其身份锚点和服装状态。未具名成员按已知数量、身份类型、服装和可见关系描述。原文人数未明时写“人数未明”；生成画面需要有限人数时，在“可视人数方案”写最小展示假设，并与原文事实分开。

成员名单、可视人数构成或集体服装显著变化时建立连续状态 `GRP-001-S01`、`GRP-001-S02`。只看到同一集体的部分成员，以及地点、光线、机位、临时队形、动作或瞬时情绪变化时，复用现有状态。调用标签固定为 `状态ID｜群像名称｜状态名称`；相同构成与服装复用 ID、锚点和标签。

## 画面与提示词

群像采用 16:9 横版纯白背景，在同一画面展示完整的全身群体；写明成员或成员类型的数量、相对位置、服装和辨识特征。具名人物沿用人物身份锚点，使脸、服装与人数在同一图中各自清晰。画面按群像版式制作，人物双手空置；剧情道具在左下独立展示，与人物身体完全分离，无道具时左下纯白留空。

固定群像版式段可直接写入完整提示词：

```text
16:9横版纯白背景，同一画面展示完整的全身群体；依据成员构成与人数安排相对位置，成员身份、服装和可辨特征清晰，人物双手空置。剧情道具在左下独立展示，与人物身体完全分离；没有道具时左下区域纯白留空。
```

完整提示词顺序：`群像锚点 → 当前成员与服装状态及具名成员引用 → 画面风格 → 固定群像版式 → 道具规则`。负面提示词合并群像通用项、已选媒介、题材和自定义排除项；群像通用项保留对“遗漏成员、额外成员、同脸复制、人物融合、成员身份漂移、服装漂移、人数违背原文、手持剧情道具、道具与手部接触、背景杂乱、文字、水印、logo”的排除。单人版式的“群像”排除词只用于单人资产。

## 群像工作表

群像 Excel 只含工作表“群像资产”；每行对应一个成员构成／集体服装状态。列顺序固定：

1. 排序
2. 群像ID
3. 状态ID
4. 群像名称
5. 状态调用标签
6. 状态名称
7. 状态判断（成员/服装）
8. 群体身份与剧情功能
9. 成员构成与人数依据
10. 具名成员人物ID/状态ID
11. 群像锚点
12. 成员与服装状态
13. 可视人数方案
14. 相对位置与辨识关系
15. 剧情道具（左下独立展示）
16. 图片比例
17. 风格ID
18. 视觉媒介
19. 题材气质
20. 自定义风格补充
21. 画面风格
22. 完整生成提示词
23. 负面提示词
24. 来源章节/段落位置
25. 使用区间
26. 状态切换依据
27. 原文依据

同一群像各状态连续相邻，按群像 ID、状态 ID 排序，群像锚点逐字一致。每行区分 `明确`、`强推断` 和 `未确认` 的来源；提示词采用有依据的事实，未确认内容留在证据或方案栏。首行加粗、冻结首行、筛选、自动换行并设置可读列宽。
