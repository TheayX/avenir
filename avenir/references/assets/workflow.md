# 资产提取工作流

只在用户请求人物、群像或场景资产时读取本文件。先按[共用原文规则](../shared/source-contract.md)确定素材和范围，再读取[共用资产约定](foundations.md)。独立提资产直接进入本流程；一步到位由[全流程编排](../pipeline.md)调用本流程。

## 选择交付范围

| 用户说法 | 内部提取 | 交付 |
| --- | --- | --- |
| 提资产、全部资产、人物＋场景 | 人物、合格群像、场景 | 人物与场景 Excel；有合格群像时加群像 Excel |
| 人物资产 | 全量个体人物、合格群像 | 人物 Excel；有合格群像时加群像 Excel |
| 只要单人 | 全量个体人物 | 人物 Excel |
| 群像资产 | 合格群像及其具名成员的内部身份档案 | 群像 Excel；无合格群像时说明筛选结果 |
| 场景资产 | 物理空间及其时间、空间状态 | 场景 Excel |

用户指定其他组合时按指定类别交付。群像候选的入选依据见[群像规范](groups.md)；无合格群像时以筛选结果结束该类别，不生成空表。

## 从素材到资产

1. **接收与通读。** 用户尚未提供素材时索取小说、剧本或分镜。素材可读时通读当前请求范围，建立章节／小节索引、人物别称、时间线、地点、服装、道具与可追溯证据。小说决定身份与剧情事实；已有分镜补充实际可见、发声和服装状态需求。素材与任务同轮到达时在同轮完成阅读与范围汇报，再推进到必要的风格选择。
2. **建立所需档案。** 人物任务按[逐节清点规则](characters.md)记录每个出场者；群像任务记录候选、成员、人数依据与入选判断；场景任务按[物理空间规则](scenes.md)记录坐标、固定结构和状态。为同一实体复用主 ID；把原文事实、强推断、弱推断和制作补足分别记录。仅交付群像时也为具名成员建立内部人物 ID、身份锚点和服装状态，供群像引用。
3. **锁定风格。** 生成 Excel 前读取[双层风格菜单](style-presets.md)。用户已明确视觉媒介与题材气质时直接锁定；其余情况依据原文推荐不超过三组，展示可点击选择题与自由文本入口。用户明确选择“默认”或“不挑风格”时使用 `STYLE-M01-G01`。确认后继续制作当前范围；同一批次复用风格 ID，明确混合风格时分批。
4. **建母版与状态。** 按[人物](characters.md)、[群像](groups.md)、[场景](scenes.md)各自规则建立稳定锚点和状态 ID。人物以服装切换分状态，群像以成员构成或集体服装分状态，场景以时间与空间状态分状态。后续章节沿用已建立的 ID、锚点和调用标签；有新证据时记录变更依据。
5. **组装与写表。** 按[提示词组装](prompt-assembly.md)形成正向完整提示词、对应负面词和版式。按[工作簿结构](workbook-contract.md)及[群像结构](groups.md)写入单表 Excel。资产图采用 16:9；人物使用双特写、三视图和左下独立道具区，群像使用全身集体图，场景使用无人的四宫格四视图。
6. **校验与交付。** 逐项执行[质量检查](quality.md)，运行适用脚本，修正后交付文件链接与处理范围。文件须可打开，表头、筛选、冻结、换行和列宽符合工作簿约定。

## 文件与校验命令

整篇或多章按资产类别各交付一份去重汇总 Excel；指定单章可在小说名后加 `_第XX章`。默认文件名为 `小说名_人物提示词.xlsx`、`小说名_群像提示词.xlsx`、`小说名_场景提示词.xlsx`。同一主 ID 的状态行连续相邻，按状态 ID 排序。保存到用户指定的可访问位置，提供文件链接。

人物覆盖清单保存为内部 JSON。交付人物资产时运行：

```text
scripts/validate_cast_coverage.py <覆盖清单.json> --characters <人物.xlsx> [--groups <群像.xlsx>]
```

对每份实际生成的工作簿运行 `scripts/validate_asset_consistency.py <资产.xlsx>`。同时有群像和人物 Excel 时，再运行 `scripts/validate_asset_consistency.py <群像.xlsx> --characters <人物.xlsx>` 核对具名成员。只交付群像且有旧人物 Excel 时用它核对；没有旧人物 Excel 时对内部人物档案逐人核对。只交付群像或场景时执行对应的单文件检查和来源审查。脚本通过后仍检查原文事实、候选遗漏和视觉状态的语义一致性。
