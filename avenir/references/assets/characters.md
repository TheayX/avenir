# 人物资产

按[资产工作流](workflow.md)确定范围和风格。本文件负责出场覆盖、人物画像、身份母版、服装状态与人物画面版式；工作表列见[工作簿结构](workbook-contract.md)。

## 逐节清点与去重

先列出当前范围的全部小说章节／小节和已有分镜的全部视频编号，再逐节扫描：

1. 读取小说中实际现身、发声或行动的人；有分镜时同时读取 `【本节出场人物】`、每镜的 `【画面】`、`【动作/情绪】`、`【台词】`、`【OS】`、`【画外音】`。
2. 把各来源取并集。出场栏列出的、画面可见的、拥有声音的、小说中实际行动的人都进入覆盖清单，包括只出现一镜、只说一句话或没有姓名的人。
3. 为每个条目保存原始称谓、标准资产名称、`character`／`group` 类型、逐节证据和对应 ID。同一人跨节合并，所有出现位置写入“来源章节/段落位置”和“使用区间”。
4. 给具名人物和可单独辨认的匿名人物建立人物资产。独立台词、独立动作、单人特写、明确关系或稳定职能都能支持单独辨认；匿名人物用场景或组织限定功能名，如“县招待所采购员”。只在原文或分镜证明同一身份时合并跨场景的匿名称谓。
5. 对只作为整体呈现的集体建立[群像候选](groups.md)；其中成员一旦独立说话、行动或获得称谓，同时建立人物资产，并在群像中引用其人物 ID。只在对白或关系说明中被提及的人，待其实际现身、发声或被分镜呈现时再记出场。

有小说和分镜时，小说决定身份事实，分镜补充制作所需的出场者。两者有差异时保留差异记录，并为分镜新增的小角色标记无小说依据的制作补足。

覆盖清单为内部 JSON，供 `scripts/validate_cast_coverage.py` 使用；`asset_name` 与 Excel 的“人物姓名”或“群像名称”逐字对应。每节同一原始称谓合并镜头证据；确实无人时用空 `entries` 并写明 `empty_reason`。只交付单人人物 Excel 时，传给脚本的清单只列 `character` 条目，群像候选保留在内部候选档案；具名或可单独辨认的群像成员仍作为 `character` 清点。

```json
{
  "sections": [
    {
      "section": "第2章 视频编号01",
      "source": "第2章 63镜.docx＋小说第2章第1节",
      "entries": [
        {"source_name": "裴长海", "asset_type": "character", "asset_name": "裴长海", "evidence": ["本节出场人物", "镜头1画面", "小说实际行动"]},
        {"source_name": "海燕三号船员群像（八人）", "asset_type": "group", "asset_name": "海燕三号遇险八人", "evidence": ["本节出场人物", "镜头3画面"]}
      ]
    }
  ]
}
```

## 证据驱动的人物画像

为每个人物建立与原文证据量相称的画像，再提炼能进入画面的稳定特征。按以下顺序读证据：

- **明确描述：** 身份、性格、目标、习惯和关系。
- **对白：** 用词、句长、礼貌程度、称谓、直接或迂回表达、情绪外露和面对不同对象的说话变化。
- **行为与决策：** 关键选择、执行方式、风险偏好、规则意识、冲突处理、压力下反应与言行关系。
- **人际与情绪：** 亲疏边界、信任与防御方式、情绪调节、矛盾面及人物变化。

证据充分的人物画像概括核心性格与矛盾面、内在驱动力与外在目标、对白风格、做事与决策风格、人际互动与情绪模式、人物弧光，并给出证据位置和置信度。`明确`表示原文直接陈述；`强推断`要求至少两处相互支持的对白或行为；`弱推断`用于单处、含混或冲突线索。提示词只采用明确事实与强推断，弱推断保存在分析栏等待后文核对。遇到矛盾证据，分别记录对应情境中的表现。

戏份少的人物照样建档。“人物画像”填写已知身份、该次行为及“稳定性格/人物弧光证据不足”；无对白时“对白风格”填“无对白，证据不足”，一句对白只记录该句可观察的表达；决策与人际栏写可见行为，缺项填“证据不足”。证据栏标明章节／小节／视频／镜头和置信度。外观信息不足时以中性、自然的最小制作补足建立可复用形象，清楚区分原文事实与补足。职业、财富、性别、年龄、籍贯或一次情绪只作为已证实的身份或当下情境信息；稳定性格、善恶、精神状况、隐秘经历和人物结局需要对应原文证据。

## 身份母版与状态

首次出场分配 `CHR-001`、`CHR-002` 等稳定人物 ID；别称、昵称、职称和第一人称指向同一角色时复用 ID。每人建立两段逐字复用的短文本：

- **身份锚点：** 性别与稳定年龄段，身高范围、骨架、肩宽和基础体态，脸型与颅面比例，眉形、眼型与眼距，鼻梁、鼻头、唇形与下颌，肤色与稳定皮肤特征，基础发际线、发色与默认发型，以及痣、疤、眼镜等永久识别点。原文缺项按最小制作补足固定。
- **可视化气质锚点：** 从有证据的稳定性格与行为方式中提炼基准神态、目光、唇部、头颈、肩背、站姿重心、动作幅度和仪容秩序。写可见、克制、适合中性资产图的描述。例：“谨慎克制”可写成“目光稳定、唇线自然收拢，肩背端正、站姿重心均衡，动作幅度小”。一次剧情情绪和动作放进场景／分镜状态，人物母版保持稳定。

同一人物的各状态行逐字复用人物画像、身份锚点和可视化气质锚点。生成平台若支持参考图、角色引用、seed 或模型参数，各状态复用同一人物母版参考与参数。

人物状态只按**服装切换**建立。通勤装、制服、礼服、居家装、睡衣、病号服、校服、伪装服等更换，以及同一套服装的明显破损、浸湿或严重脏污，分别建立新状态。表情、姿势、机位、手势、手持物、环境和瞬时情绪沿用当前服装状态；妆发、疲惫、伤病和年龄依据原文记录在该状态提示词中，服装相同时继续复用状态 ID。

每人至少有基础服装状态，使用连续 `CHR-001-S01`、`CHR-001-S02` 编号。状态名称直接写服装，如“基础通勤装”“住院病号服”；调用标签固定为 `状态ID｜人物姓名｜状态名称`。相同服装再次出现时复用原状态 ID、名称和调用标签，并合并来源区间。

## 画面版式与提示词

人物资产图为 16:9 横版、纯白背景。左上放同一人物的正面与侧面面部特写，两张使用一致的五官、发型、妆容和服装状态；右侧放正面、侧面、背面全身三视图，保持同一脸、身材、发型和服装。人物自然站立，手臂自然下垂或置于身体两侧，双手空置。

左下为剧情道具独立展示区，位置在两张面部特写下方。剧情需要的手机、文件、包裹、武器、杯子、钥匙、书本或工具等物件，单独排列在左下，与人物完全分离、无遮挡、无手部接触；多个道具互不重叠。无剧情道具时左下纯白留空。眼镜、耳饰和穿戴在身上的服装配件留在人物视图中。

完整提示词顺序：`身份锚点 → 可视化气质锚点 → 服装状态 → 画面风格 → 固定人物版式 → 剧情道具规则`。`画面风格` 的内部组成见[提示词组装](prompt-assembly.md)。单人资产的负面词与正向版式配套使用，详见同一文件。
