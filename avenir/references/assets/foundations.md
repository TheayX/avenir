# 资产共用约定

人物、群像和场景共用以下来源、状态、风格与交付规则。具体判断分别见对应资产文件。

- **来源。** 读取当前范围的完整小说、剧本或分镜，建立章节／小节与证据索引。有小说时以小说核对身份和剧情事实；只有分镜时只确定分镜能证明的内容。制作需要而原文未写出的视觉细节，标记“制作补足”，选用最小、合理的方案并持续复用。
- **画布。** 三类资产图均为 16:9。场景提示词指定目标 8K、7680×4320；人物与群像使用 16:9 横版画布。
- **实体与状态。** 全书或本次多章范围先去重，再为同一人物、群像或物理空间分配一个稳定主 ID。每条记录包含主 ID、状态 ID、状态调用标签、来源章节／段落位置、使用区间与原文依据。相同状态跨章复用原行，并合并来源与使用区间。
- **母版与增量。** 先写逐字复用的身份／群像／空间锚点，再写服装、成员构成或时间／空间状态的增量。生成提示词每行完整复用本实体的不变锚点；新证据改变设定时记录依据，并统一修订受影响的状态行。
- **风格。** 资产生成前按[双层风格菜单](style-presets.md)确认视觉媒介和题材气质。人物、群像和场景在同一批次使用同一风格 ID、母版与有效自定义补充。风格负责视觉表达，原文事实、主 ID、状态划分、画布比例和版式按各自规范保持稳定。
- **工作簿。** 每种实际交付的资产各用一个 Excel、一个对应工作表。同一主 ID 的状态行连续相邻，按主 ID、状态 ID 排序。仅请求提示词时也先完成范围阅读、覆盖清点、状态和调用区间映射，再制作相应内容。
