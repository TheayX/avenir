# 原文、范围与共用档案

分镜和资产共用小说事实，不共用彼此的输出格式。首次收到完整小说时通读序言、导语、正文、番外及结尾；只处理用户指定的章节范围，但理解人物关系、时间线、伏笔和空间时参考已读全篇。原文未给出的姓名、年龄、外貌、地点、关系与经历保持未知，制作所需的少量视觉补足须标明依据并固定复用。

内部记录章节边界、原文段落位置、人物姓名与别称、关系、对白、行为、各阶段人物已知与未知的事实、事件顺序、场景及空间结构、时间光效、服装变化、关键道具、金额、日期、地址、消息和证据。分镜只呈现当前剧情时点可知的信息，不用后文提前揭示真相。

资产提取时再建立逐节出场覆盖清单和人物／群像／场景 ID 映射。有小说和分镜时，小说决定人物身份与剧情事实；分镜的出场栏、画面、动作、台词、OS 与画外音补足实际资产需求。两者冲突时记录差异，不因分镜漏列而删去小说当前段落的实际出场者，也不因小说戏份少而删去分镜需要的人物。只有一种素材时只陈述该素材能支持的事实。

整篇处理按原文顺序逐章推进，指定单章只对该章交付，跨章复用已有身份、空间与状态锚点。续做时优先读取用户提供的前版分镜或资产 Excel；同一人物、群像和物理场景沿用原 ID。已有资产不可访问时，先说明无法核对旧 ID 的范围，再为当前材料建立可追溯的新档案。素材空白、损坏、加密或缺少指定章节时索取可读版本。
